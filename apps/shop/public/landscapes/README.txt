Ainthinai section background photos (optional).

Drop one landscape photo per thinai here and the matching home-page section
switches from the faint terrain line-art to that photo (under a legibility
scrim). Remove a file and the section falls back to the terrain automatically.

Filenames (first match wins; .jpg .jpeg .png .webp):
  marutham.jpg  — farmland / paddy field + river   (hero + farmer + marketplace + contact)
  mullai.jpg    — forest / pasture / jasmine        (why + consumer journey + FAQ)
  neithal.jpg   — seashore / boats                  (ecosystem + testimonials + pricing)
  kurinji.jpg   — hills / mountains / tea slopes    (statistics + updates)
  palai.jpg     — dry plain / dunes                 (business + sustainability)

Guidance: landscape orientation, ~1600px+ wide, calm/mid-tone scenes work best
(the scrim lightens them). Text stays dark on all five, so avoid photos that are
already very pale in the upper-left where headings sit.
